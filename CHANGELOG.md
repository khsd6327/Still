# Changelog

## 0.1.0-alpha.1

Initial public development preview.

1. Native SwiftUI bottle, engine, application, and process management.
2. Public Wine engine catalog with pinned downloads.
3. Steam installation, launch, library discovery, and helper filtering.
4. Per-process stop, bottle stop, and stop-all controls with menu commands and
   keyboard shortcuts.
5. Wine 11.14 Steam CEF presentation and ANGLE compatibility patches.
6. Wine-to-DXMT macdrv bridge source and build tooling.
7. Direct3D 11 rendering validation for two Windows games on Apple silicon.

Known limits: the DXMT engine assembly is manual; sustained gameplay, audio,
save integrity, performance, broad compatibility, signing, notarization, and
automatic updates are not validated.
